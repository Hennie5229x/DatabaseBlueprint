## Installation

### Linux (amd64)

```bash
sudo curl -L \
  https://github.com/Hennie5229x/DatabaseBlueprint/releases/latest/download/blue-linux-amd64 \
  -o /usr/local/bin/blue

sudo chmod +x /usr/local/bin/blue
```

### macOS (Apple Silicon)

```bash
sudo curl -L \
  https://github.com/Hennie5229x/DatabaseBlueprint/releases/latest/download/blue-darwin-arm64 \
  -o /usr/local/bin/blue

sudo chmod +x /usr/local/bin/blue
```

Then verify the installation:

```bash
blue version
```
